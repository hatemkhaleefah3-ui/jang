The pipeline

Four clear steps. One clean file.

01

Import

Select a PPTX, PDF, or HTML lecture. Parsing and media extraction happen locally in the browser.

02

Extract

Readable text, slide structure, embedded images, SVG, and relevant PDF page snapshots are identified.

03

Rebuild

Gemini creates a content plan when configured; otherwise Jang creates a source-preserving local layout.

04

Download

A PowerPoint deck and a self-contained HTML lecture are generated in the browser.

# Text builder verification

The deterministic text builder accepts pasted content and imported UTF-8 `.txt` content through the same parser. It verifies that every parsed block is emitted exactly once and in source order before preview, saving, or export is enabled.

The supplied Immunoglobulin lecture format is covered by parser and browser tests for document titles, topic maps, information and note boxes, sections, paragraphs, lists, Markdown tables, image labels, diagrams, pathways, quick review blocks, and footers.
